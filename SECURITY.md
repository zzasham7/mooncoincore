# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately using one of these channels:

1. GitHub Security Advisory (preferred) on this repository.
2. Direct maintainer contact listed on the project website/repository profile.

Do not open public issues for unpatched security vulnerabilities.

## Scope

Security reports are especially important for:

- Consensus validation
- P2P message handling
- Wallet key management and signing paths
- RPC authentication/authorization
- Build/release integrity

## Disclosure Process

- Acknowledge receipt.
- Reproduce and triage.
- Prepare a fix and test coverage.
- Coordinate release timing where needed.
- Publish advisory notes after patch availability.
