Repository Tools
----------------

This folder contains operational and developer helper tools that remain in active use for Mooncoin Core.

Active subfolders
-----------------

- `contrib/debian`: packaging metadata.
- `contrib/devtools`: maintenance scripts.
- `contrib/linearize`: blockchain linearization helpers.
- `contrib/macdeploy`: macOS packaging helpers.
- `contrib/qos`: bandwidth shaping helper script.
- `contrib/seeds`: seed generation utilities.
- `contrib/testgen`: test vector generation helpers.
- `contrib/windeploy`: Windows deploy helper scripts.
- `contrib/zmq`: ZMQ examples/tools.

Notes
-----

Legacy upstream release-signing and historical build tooling directories were removed in this curated branch to reduce operator confusion.
