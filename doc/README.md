# Mooncoin Documentation

This directory contains the operational and developer documentation for Mooncoin Core.

## Core docs

- [build-unix.md](build-unix.md): Native Linux/Unix build from source.
- [build-windows.md](build-windows.md): Windows x64 cross-build from WSL/Linux using `depends`.
- [dependencies.md](dependencies.md): Dependency baseline for current branch.
- [mooncoin-conf.md](mooncoin-conf.md): `mooncoin.conf` reference and path notes.
- [JSON-RPC-interface.md](JSON-RPC-interface.md): RPC security and usage notes.
- [zmq.md](zmq.md): ZMQ notifier setup.
- [BUILD_DEPS_UBUNTU_ARM64.md](BUILD_DEPS_UBUNTU_ARM64.md): validated ARM64 VPS dependency set.

## Subdirectories

- `mweb/`: technical notes for MWEB-related internals.

## Scope policy

This branch is intentionally curated for Mooncoin operations and maintainability.
Legacy upstream release-note archives and migration handoff notes are removed from public-facing docs.
